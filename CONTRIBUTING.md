# Contributing to cmsg

cmsg is the FSL-licensed private messaging core. Please keep commercial
copy and deployment config out of this repository; those belong in the
frontend layer.

## Contributor License Agreement

We can only accept contributions covered by the Individual Contributor
License Agreement, version 1.0:

https://github.com/corbet-labs/.github/blob/cla-v1.0/CLA.md

To affirm it, include this line in your pull request description:

> I affirm the Individual Contributor License Agreement v1.0 (cla-v1.0)
> for this contribution.

Pull requests without that affirmation cannot be merged. This keeps fixes
movable between layers while relicensing rights stay with the licensor.
