# Component composition experiment

This local synthetic harness executes actual cvld AnonCreds issuance and presentation, software-authenticator WebAuthn enrollment/login, cfrm certified onion rendezvous, RFC9474 blind first-contact permits, and the native cmsg OpenMLS participant. Two separately certified members discover each other, consume a finite permit, exchange authenticated text, and restore an encrypted snapshot. Negative checks reject copied certificates, permit replay, message replay and reconnect-based allowance refill. Expired presence is removed by timers.

The workflows pin both sibling repositories by full commit and install only their locked dependencies on a permitted runner. They use no real phone number, payment, production key or paid provider. The initial workflow failed during checkout because abbreviated sibling revisions were unsuitable; it is not counted as a behavioral red run. The first actual composition passed in [run 34258756285](https://github.com/corbet-labs/cmsg/actions/runs/34258756285), commit `7d10044`.

The recipient-enforced composition passed in [manual CI run 5](https://crow.corbet.ch/repos/10/pipeline/5), cmsg source `8ede4f139e452f37733ac7cfe6e3ca32f8d3d30f`, with cvld `9d8dfb642a0a9e53eed8069a757d400c82cd4b11` and cfrm `507b63c775c4869d08f255d0a0c11866a2bf9249`. The native Inbox validates the actual Welcome and inviter, persists the recipient-generated pending claim before requesting redemption, then commits the joined conversation and known inviter before exposing success. The actual cfrm ledger accepts an exact retry while rejecting another claim and an ordinary second spend. The test restores the encrypted recipient checkpoint and rejects message replay.

This is a process-level composition, not a network deployment. Provider attestations are signed synthetic fixtures, PRF output is synthetic input to the real wallet derivation, and onion addresses are validated test endpoints with no connection attempted here. Actual browser PRF and Tor circuits have their own experiments. The harness temporarily holds both clients' state to drive the test; this is not an operator-service architecture.

The allowance request/response adapter is still local orchestration, not an anonymously transported service. This composition does not yet include private reciprocity, a live provider uniqueness service, mobile lifecycle management or production telemetry. Bearer permits remain transferable, and timing correlation remains outside their cryptographic blindness guarantee. Do not expose this harness as a service.

To reproduce on a permitted build runner, check out cmsg, cvld and cfrm as siblings at the workflow revisions, install cvld and the cfrm anonymous-permit experiment dependencies, build `cargo build --locked --example composition` in cmsg, then run `node --test experiments/composition/composition.test.mjs`.
